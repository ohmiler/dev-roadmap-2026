## ✨ Features

- 📱 **Responsive Design** - รองรับทุกขนาดหน้าจอ
- 🎨 **Premium White Theme** - ธีมขาวสวยงามสไตล์ Developer
- ⚡ **Smooth Animations** - Animation ลื่นไหลด้วย CSS
- 🔗 **Clickable Resources** - Links ไปยังแหล่งเรียนรู้จริง
- 📖 **6 Phases ครบถ้วน** - ครอบคลุมทุกทักษะที่จำเป็น

## 🛠️ Tech Stack

- **Build Tool:** Vite 5.0
- **Languages:** JavaScript (ES6+), CSS3, HTML5
- **Fonts:** Inter, Prompt (Google Fonts)
- **Design:** Glassmorphism, Timeline Layout

## 🚀 Quick Start

```bash
# Clone repository
git clone <your-repo-url>
cd 2026-roadmap

# Install dependencies
npm install

# Run development server
npm run dev
```

เปิด http://localhost:5173

## 📦 Build for Production

```bash
npm run build
npm run preview
```
