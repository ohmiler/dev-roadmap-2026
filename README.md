# 🚀 Developer Roadmap ในยุค AI (2026)

## ✨ Features

- **9 ช่วง · 64 หัวข้อ · 364 ทักษะย่อย** ตั้งแต่ Mindset จนถึง Human Edge
- **รายละเอียดทุกหัวข้อ**: ทำไมสำคัญในยุค AI, เช็กลิสต์ทักษะ, เคล็ดลับใช้ AI ช่วยเรียน, โปรเจกต์ฝึกมือ และแหล่งเรียนรู้
- **ติดตามความคืบหน้า**: ติ๊กทักษะย่อย หรือกดวงกลมบนการ์ดเพื่อทำเครื่องหมายว่าเรียนจบทั้งหัวข้อ (มีปุ่มเลิกทำ) บันทึกในเบราว์เซอร์ พร้อมส่งออก/นำเข้าเป็น JSON
- **แบบทดสอบหาจุดเริ่มต้น** 4 คำถาม แล้วบันทึกเป็นกล่อง “เส้นทางของฉัน” พร้อมไฮไลต์ 5 หัวข้อถัดไปที่ควรโฟกัสใน Roadmap
- **กรองตามสายงาน**: Frontend, Backend, Full-stack, AI Engineer, Data / ML, DevOps / Platform, Mobile (เลือกได้ว่าจะแสดงหัวข้อนอกสายแบบจางหรือซ่อน)
- **แถบเลือกช่วง 00–08** ติดหน้าจอบนมือถือ/แท็บเล็ต และสารบัญด้านข้างบนจอกว้าง
- **Prompt สำเร็จรูป** คัดลอกไปเรียนกับ AI แบบ Socratic ได้ทันที (ปรับตามทักษะที่ยังไม่ได้เรียน)
- **Skill Matrix**: แผนภาพ “AI ทำแทนได้แค่ไหน” เทียบ “คุณค่าระยะยาว” แบ่ง 4 โซน พร้อมมุมมองตาราง
- ค้นหา (กด `/`), พับแถบตัวกรองเหลือแถวเดียวได้, Light / Dark mode, รองรับมือถือ และใช้งานด้วยคีย์บอร์ดได้

## 🛠️ การใช้งาน

ทั้งเว็บอยู่ใน `index.html` ไฟล์เดียว เปิดในเบราว์เซอร์ได้ทันทีโดยไม่ต้อง build

หรือรันผ่าน Vite:

```bash
npm install
npm run dev
```

Build สำหรับ deploy (ได้ `dist/index.html`):

```bash
npm run build
```
